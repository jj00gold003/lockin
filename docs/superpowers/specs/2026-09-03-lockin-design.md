# LockIn 设计文档

日期：2026-09-03
状态：已与用户确认的设计定稿

## 1. 产品定位

**LockIn** 是一款免费开源的 macOS 生产力应用，托管于 GitHub，通过 Releases 分发。

- **目标用户**：知识工作者 / 开发者——需要长时间深度工作、愿意为效率工具配置权限的人群
- **核心卖点**：深度工作防护——干扰屏蔽（应用监控 + 拦截遮罩）与专注会话深度联动
- **商业模式**：无。免费、开源、无广告、无内购、无遥测
- **传播目标**：GitHub Stars。关键手段：README 顶部演示 GIF、Homebrew cask 一行安装、Hacker News / r/macOS / V2EX 首发

## 2. 技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 平台 | macOS 14+ | SwiftUI 生态成熟；14+ 覆盖绝大多数 Mac |
| UI 框架 | SwiftUI | 原生性能、菜单栏/系统集成体验最佳 |
| 数据 | SwiftData（纯本地） | 无账号无云端，隐私最强，开发最简 |
| 本地化 | String Catalog 中英双语 | 面向全球开发者，双语同步维护 |
| 分发 | GitHub Releases + 公证（notarization）+ Homebrew cask | 免沙盒限制，屏蔽能力可做到最强 |
| 语言 | Swift 5.10+ | — |

明确不使用：Electron/Tauri（系统集成能力受限）、守护进程架构（v1 过度设计）。

## 3. 整体架构

```
LockIn/
├── App/                    # 入口、窗口管理、菜单栏项
├── Core/
│   ├── TimerEngine/        # 专注/番茄计时核心（与 UI 无关，可单测）
│   ├── Blocker/            # 干扰屏蔽引擎（应用监控 + 拦截 + 遮罩）
│   └── Storage/            # SwiftData 模型与仓储层
├── Features/
│   ├── Focus/              # 专注会话界面
│   ├── Tasks/              # Todo 列表
│   ├── Habits/             # 习惯打卡
│   └── Stats/              # 统计面板
└── Shared/                 # 主题、本地化、通用组件
```

- **TimerEngine 与 Blocker 是纯逻辑模块**：不 import SwiftUI、不依赖界面，可独立单元测试；未来升级为守护进程无需重写。
- **窗口结构**：
  - 主窗口：侧边栏四板块（专注 / 任务 / 习惯 / 统计）
  - 菜单栏项：迷你计时器 + 快捷控制（开始/暂停/跳过）+ 展开小面板
  - 屏蔽遮罩窗口：专注中打开黑名单应用时的全屏拦截层

## 4. 屏蔽引擎（核心功能）

### 4.1 工作原理

1. `NSWorkspace` 订阅系统通知，实时获知前台应用（**无需任何权限**）。
2. 前台应用命中黑名单时两级响应：
   - **软拦截**（默认）：弹出置顶拦截窗口盖住分心应用，显示"正在专注中"倒计时 + 当前会话关联任务；切回允许的应用自动消失。
   - **硬拦截**（增强，需辅助功能权限）：将分心应用最小化/切走，并在会话结束前禁止再次激活。
3. 网页分心 v1 按**浏览器应用**粒度拦截（整个 Chrome/Safari 入黑名单）；网址级屏蔽需浏览器扩展，属 v2。

### 4.2 权限模型（全部本地，无网络）

- 零授权 → 应用监控 + 软拦截可用（覆盖 80% 体验）
- 辅助功能权限 → 硬拦截
- 首次启动引导流程解释权限用途；权限缺失时入口置灰 + 内嵌"去系统设置"按钮，不用报错弹窗轰炸。

### 4.3 防作弊设计

- 会话进行中退出 LockIn 需确认；强行中断记为"失败会话"进入统计。
- 会话开始后黑名单锁定，不能临时删规则开后门。
- 拦截事件本地留痕（哪个应用、几秒后返回），统计页透明可见——用数据激励而非惩罚。

### 4.4 规则数据结构

黑名单 = 应用列表（bundleID）+ 生效时段（如"工作日 9:00–18:00"或"仅专注会话中"）+ 拦截级别（软/硬）+ 启用状态。

## 5. 计时引擎与数据模型

### 5.1 TimerEngine

状态机：`空闲 → 专注中 → 暂停 → 恢复/放弃 → 休息中 → 循环或结束`

- **不逐秒计时**：记录锚点时间戳，剩余时间 = 目标时长 − 已流逝（`Date` 计算），休眠/唤醒后自动校准。
- 会话类型：
  - **番茄钟**：25/5 循环，4 轮后 15 分钟长休，全部可配置
  - **自由专注**：无上限，手动结束
- 会话可关联一个 Todo 任务，结束自动累计专注时长（四大件的黏合点）。
- 每次会话完整落库：起止、类型、状态、关联任务、中断次数、拦截触发次数。

### 5.2 SwiftData 模型（5 实体）

```
Task      # Todo：标题、备注、优先级、截止日、预估番茄数、累计专注时长、完成状态
Habit     # 习惯：名称、图标、频率（每日/每周N次）、颜色、创建日期
HabitLog  # 打卡：日期、习惯、备注 —— 按日查询画热力图
Session   # 会话：起止、类型、状态(完成/中断)、关联Task、中断次数、拦截次数
BlockRule # 规则：应用bundleID、时段、软/硬级别、启用状态
```

- 习惯打卡：连续天数（streak）、本周完成度、GitHub 风格年度热力图。
- 统计页：今日/本周/全部专注时长、会话完成率、分心拦截曲线、习惯热力图、按任务时间分布——全部由上述实体聚合查询，不加表。

## 6. 错误处理

- **权限缺失**：降级路径优先；硬拦截入口置灰 + 跳转系统设置按钮。
- **休眠/唤醒**：监听 `NSWorkspace.willSleepNotification`，唤醒后按锚点校准；休眠超过休息时长自动结束该轮并如实记录。
- **崩溃/强退恢复**：会话状态每次变更即时落库；重启检测到未闭合会话时询问"继续/结束/丢弃"。
- **本地化**：所有用户可见文案走 String Catalog，禁止硬编码，纳入 CI 检查。

## 7. 测试策略

- TimerEngine、Blocker 规则匹配、统计聚合：XCTest 单元测试，覆盖核心路径。
- 测试分心应用用系统自带"便笺"（`open -a Notes`），不装真实干扰应用。
- UI 层不做自动化快照测试，靠手工验收清单。
