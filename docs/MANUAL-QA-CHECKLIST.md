# LockIn v1 手工验收清单

## 功能
- [ ] 番茄钟 25/5 循环、第 4 轮长休 15 分钟、时长流转正确
- [ ] 自由专注计时、手动结束
- [ ] 暂停/继续/跳过休息/放弃全部可用且统计如实
- [ ] 专注会话可关联任务，结束后任务累计时长增加
- [ ] Todo：增/删/完成/优先级排序
- [ ] 习惯：新建/打卡/取消/streak/热力图
- [ ] 软拦截：专注中打开黑名单应用出现全屏遮罩，切回正常应用消失
- [ ] 硬拦截：授权辅助功能后黑名单应用被最小化；未授权自动降级为软拦截
- [ ] scheduled 时段规则在时段内/外行为正确
- [ ] 会话开始后黑名单规则锁定（删除规则不影响进行中会话的拦截）
- [ ] 会话进行中退出 App 弹确认；强杀后重启出现恢复弹层
- [ ] 统计：今日/本周时长、7 天柱状图、拦截曲线
- [ ] 菜单栏：图标/倒计时/全部控制按钮

## 界面冒烟（GUI smoke）
- [ ] 菜单栏倒计时逐秒刷新（开始专注后秒级跳动，暂停/结束即停）
- [ ] 黑名单应用（如备忘录外的其他应用）触发全屏遮罩，遮罩浮于应用之上
- [ ] 硬拦截最小化：授权辅助功能后黑名单应用被强制最小化
- [ ] 强杀后恢复弹层三按钮（继续专注/标记完成/丢弃）
- [ ] 系统语言 en / zh-Hans 下界面文案正确
